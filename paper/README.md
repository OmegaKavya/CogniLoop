# Paper

The manuscript for this work is under review and its source is not tracked
here. What remains in this directory is the material the paper's
reproducibility statement actually refers to:

- `figures/` — the figures, regenerated by the scripts below
- `estimator_confound.bib`, `acmtrans.bst` — bibliography

Every number in the paper is produced by committed code, not transcribed:

| Exhibit | Produced by |
|---|---|
| Table 1, Figure 1 | `scripts/make_geometry_figure.py` (analytic) |
| Table 2, Figure 2 | `scripts/make_inflation_figure.py` |
| Table 3, Figure 3 | `scripts/make_asymmetry_figure.py` |
| Tables 3 and 4 | `scripts/latent_learning_simulation.py` |

`make_asymmetry_figure.py` asserts every value it plots against the published
table and fails rather than drawing a figure that disagrees with the text.
